# Kyra Quest Launch App

![TypeScript](https://img.shields.io/badge/TypeScript-informational?style=flat-square)

> Kyra Quest Launch App — part of [@nickthelegend](https://github.com/nickthelegend)'s work.

## Tech Stack

**ethers.js** · **Framer Motion** · **Next.js** · **React** · **viem** · **Tailwind CSS** · **TypeScript**

## Getting Started

```bash
# clone
git clone https://github.com/nickthelegend/kyra-quest-launch-app.git
cd kyra-quest-launch-app

pnpm install
pnpm run dev
pnpm run start
pnpm run build
```
